7 · 建议（按优先级）

  • ① 统一方言 —— 浅色（A/E/D）与深色（B/C）并存，输入框尺寸、关闭键几何、底栏机制各不相同。建议门禁类统一为深色方言（安全语义更契合），二选一，不要并存。
  • ② 落地权威令牌 —— #1a1a17 → --color-dark-container、rounded-2xl → --radius-console-xl(8px)、shadow-2xl → --shadow-console-2，即可消除第 5 节全部偏差。
  • ③ 抽公共基座 —— A–E 共享约 70% 结构，建议抽 AuthGateShell / AuthGateField / AuthGateCard 三个原子组件。
  • ④ 补 A11y —— 至少实现 Esc 关闭 + role="dialog" + aria-label，成本极低。
  • ⑤ 移除演示痕迹 —— 888888 / admin888 / 8888 三处明文提示与万能放行码，建议用 import.meta.env.DEV 条件渲染。
  • ⑥ 补移动端策略 —— A/E 头部横幅、D 双栏对照在 <480px 无专门压缩，可启用项目已定义的 --breakpoint-xs: 480px。
